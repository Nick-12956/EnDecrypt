# EnDecrypt

A simple Python-based encryption and decryption tool built with `cryptography` and `tkinter`.

This project allows you to:
- Encrypt a message
- Decrypt a message
- Encrypt a file
- Decrypt a file
- Generate a secure Fernet key

## Features

- Secure encryption using `Fernet`
- File selection via a GUI dialog
- Message encryption/decryption
- File encryption/decryption
- Easy terminal-based menu system

## Tech Stack

- Python 3
- `cryptography`
- `tkinter`

## Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/endecrypt.git
cd endecrypt
```

2. Install dependencies:
   pip install cryptography
   
3. Run the script:
   python endecrypt.py
